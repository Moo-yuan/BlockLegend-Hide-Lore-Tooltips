========================================
【模组功能概述】
========================================

本模组是一个客户端Fabric模组，用于在BlockLegend RPG服务器中自定义隐藏物品的Lore/NBT提示信息。

核心功能:
1. 隐藏附魔（原版+插件+老版本）
2. 隐藏附魔描述
3. 隐藏RPG属性（攻击伤害/速度/暴击等）
4. 隐藏技能组（技能名+冷却/持续）
5. 隐藏符文/宝石槽（空槽/全部）
6. 隐藏底部信息（耐久/绑定/击杀/无法破坏）
7. 原版属性移除（纹饰/工具属性/护甲属性）
8. 材料保护（Paper/Feather/Stick）
9. 自定义按键展开隐藏内容（默认 Caps Lock）

========================================
【自定义按键功能】
========================================

【实现方式】
- 不注册 Fabric KeyBinding（避免显示在原版按键设置中）
- 纯配置项控制，通过 ModMenu 配置界面下拉列表选择
- 使用 GLFW 直接检测按键状态

【可选按键】
- Caps Lock（默认）
- Left Ctrl
- Left Alt
- Left Shift
- Right Shift

【配置位置】
- ModMenu → BlockLegend Hide Lore Tooltips → 原版修改 → 自定义展开按键
- 配置文件: .minecraft/config/blocklegend_hidelore.json

【提示文本变量】
- {key} - 自动替换为当前选择的按键名称
- {count} - 隐藏信息行数

【配置系统】
========================================

配置框架: AutoConfig + Cloth Config + Jankson
配置文件路径: .minecraft/config/blocklegend_hidelore.json

配置项列表（16个）:

[Lore修改页]
1. enabled                    - 启用模组（总开关）
2. hideEnchantments           - 隐藏所有附魔（原版+插件+老版本）
3. hideEnchantmentDesc        - 隐藏所有附魔描述（原版+插件，老版本无描述）
4. hideAttributes            - 隐藏属性
5. hideSkills                - 隐藏技能组
6. hideEmptySlots            - 隐藏空符文/宝石槽
7. hideAllSlots              - 隐藏全部符文/宝石槽
8. hideDurability            - 隐藏耐久度
9. hideBoundStatus           - 隐藏已绑定
10. hideKillCount            - 隐藏击杀人数
11. hideUnbreakable          - 隐藏无法破坏
12. unbreakableOverridesDurability - 无法破坏替代耐久
13. hintText                 - 提示文字（精简模式底部显示，支持{key}和{count}变量）
14. separatorLine            - 分隔线（展开模式显示）

[原版修改页]
15. customKey                - 自定义展开按键（默认Caps Lock）
16. hideArmorTrim            - 隐藏纹饰
17. hideVanillaToolStats     - 隐藏原版工具属性
18. hideVanillaArmorStats    - 隐藏原版护甲属性
19. protectEnchantedBook     - 保护附魔书
20. protectPaper            - 保护材料（Paper/Feather）
21. boldUnbreakable          - 无法破坏加粗

默认值:
- enabled: true
- hideEnchantments: false
- hideEnchantmentDesc: false
- hideSkills: true（默认隐藏技能）
- customKey: CAPS_LOCK
- 其他: false
- protectEnchantedBook: true
- protectPaper: true
- boldUnbreakable: true

========================================
【8分区识别系统】
========================================

物品Lore从上到下分为8个区域，按优先级识别:

区域0: 名称行（第0行，固定保留）
区域1: 附魔区（附魔名称+附魔描述）
区域2: 类型2区（星级枩+等级Lv.+武器类型戞[...]）
区域3: 属性区（RPG前缀+属性关键词）
区域4: 元素区（元素前缀+元素类型+伤害/防御）
区域5: 技能区（触发词+技能名+冷却/持续+空白）
区域6: 符文/宝石区（空槽/已镶嵌）
区域7: Lore文本区（渐变文本+套装信息）
区域8: 底部区（耐久/绑定/击杀/无法破坏）

识别优先级: 名称 > 附魔 > 类型2 > 属性 > 元素 > 技能 > 宝石 > Lore > 底部

========================================
【附魔识别逻辑】（核心优化）
========================================

【附魔库结构】
- 原版附魔: 42个（VANILLA_ENCHANTMENTS）
- 插件附魔: 179个（PLUGIN_ENCHANTMENTS）
- 老版本附魔: 83个（LEGACY_ENCHANTMENTS）
- 附魔前缀: 鬸、鬹、鬻、鬺（PLUGIN_ENCHANTMENT_PREFIXES）
- 总附魔数: 304个

【附魔描述库】
- 原版附魔描述指示词: 约50个关键词（用于识别附魔描述行）
- 插件附魔描述指示词: 约120个关键词

【识别流程】
1. 逐行扫描Lore
2. 检查是否是附魔名称（硬匹配304个附魔）
3. 如果是附魔名称 → 标记 isEnchantment = true
4. 进入附魔区域扫描模式
5. 在附魔区域内:
   - 检查是否是附魔描述（匹配描述库关键词）
   - 检查是否遇到其他区域开头（终止附魔区域）
   - 检查是否是空行（判断下一行是否还是附魔相关）
6. 附魔区域外的行不再被判定为附魔

【关键规则】
- 附魔区域一旦终止，后续行不会被误判为附魔描述
- 空行处理: 空行后紧跟新附魔或附魔描述 → 空行归入附魔描述
- 空行后紧跟其他区域 → 空行不归入附魔，终止附魔区域
- 老版本附魔: 只标记 isEnchantment，不扫描描述（isLegacyEnchantment标记）

【隐藏逻辑】
- hideEnchantments = true → 隐藏所有 isEnchantment = true 的行
- hideEnchantmentDesc = true → 隐藏所有 isEnchantmentDesc = true 的行
- 两个开关独立控制

========================================
【自定义按键检测逻辑】
========================================

【检测方式】
- 使用 GLFW.glfwGetKey() 直接检测按键状态
- 不注册 Minecraft KeyBinding（避免显示在原版按键设置中）

【按键映射】
- CAPS_LOCK: GLFW_KEY_CAPS_LOCK (280)
- LEFT_CONTROL: GLFW_KEY_LEFT_CONTROL (341)
- LEFT_ALT: GLFW_KEY_LEFT_ALT (342)
- LEFT_SHIFT: GLFW_KEY_LEFT_SHIFT (340)
- RIGHT_SHIFT: GLFW_KEY_RIGHT_SHIFT (344)

【提示文本】
- 默认: "§7[按 {key} 查看 {count} 条隐藏信息]§r"
- {key} 自动替换为当前选择的按键显示名称
- {count} 替换为隐藏行数

========================================
【元素识别逻辑】
========================================

【元素库】
- 6种元素: 冰(鐮)、电(鐨)、水(噕)、风(鍏)、暗黑(☽)、火(曞)
- 2种属性: 元素伤害、元素防御

【识别条件】
1. 必须包含元素前缀（6种之一）
2. 必须包含元素类型（6种之一）
3. 必须包含属性关键词（伤害/防御之一）

【示例】
- "50%风元素伤害" → 匹配（前缀鍏+类型风+关键词伤害）
- "10%冰元素防御" → 匹配（前缀鐮+类型冰+关键词防御）

========================================
【技能识别逻辑】
========================================

【触发词库】
- 攻击时、左键、右键、Shift+右键、Shift+左键、SHIFT、被动技能、终结技

【冷却词库】
- 冷却、持续、间隔、蓄力、Timer

【保护词库】
- 切换模式、组合技、Shift+右键+右键、双SHIFT

【识别流程】
1. 检查是否是保护关键词 → 跳过，不归入技能
2. 检查是否包含触发词 → 标记技能区域开始
3. 技能区域内:
   - 冷却行 → 归入技能
   - 空白行 → 归入技能，终止区域
   - 新触发词 → 归入技能（连续技能）
   - 其他内容 → 终止技能区域

【技能区块结构】
- 有冷却: 触发词 + 技能名 + 冷却行 + 空白行 = 4行整体
- 无冷却: 触发词 + 技能名 + 空白行 = 3行整体
- 被动技能: 触发词 + 技能名 + 持续/间隔行 + 空白行

========================================
【属性识别逻辑】
========================================

【RPG前缀】
鄿(攻击)、嬫(技能)、竴(暴击)、嫨(远程)、鐖(防御/生命)、鍏(风)、曞(火)

【属性关键词】
攻击伤害、攻击速度、暴击几率、暴击伤害、技能伤害、技能冷却、
法力值、技能暴击率、技能暴击伤害、远程伤害、招架几率、
击退抗性、闪避几率、生命值、基础防御、命定指数

【识别条件】
1. 必须包含RPG前缀（8种之一）
2. 必须包含属性关键词（16种之一）

【排除规则】
- 不包含RPG前缀的"攻击伤害"等 → 不归入属性区（防止原版属性误判）

========================================
【工具识别逻辑】
========================================

【工具类型】
- 镐子(netherite_pickaxe): 无类型2，无属性
- 斧子(netherite_axe): 有类型2，有属性
- 铲子(netherite_shovel): 无类型2，无属性
- 钓竿(fishing_rod): 有类型2，有钓鱼属性
- 盾牌(shield): 有类型2，有防御属性

【工具文本特征】
- 分隔线: ====== 或 ------
- 功能描述: "此工具可"、"能连锁"、"每次挖掘"等
- 保护关键词: "Shift+右键切换模式"

========================================
【Lore文本识别逻辑】
========================================

【识别条件】（满足任一）
1. 包含"通过 铁匠锻造 获得/获取"
2. 包含"套装:"或"套装："
3. 包含"[4]"或"[5]"套装效果前缀
4. 包含分隔线（======或------）
5. 包含工具文本关键词
6. 匹配变量模板（"由XX制作的头盔/胸甲/护腿/靴子"）

【扩展规则】
- 识别到Lore文本后，向前后扩展，把相邻的空白行也归入Lore区
- 空白行如果相邻有Lore行，也归入Lore区

========================================
【底部区识别逻辑】
========================================

【D方案】（当前使用）
- 只标记底部行本身
- 不向上扫描空白行
- 底部关键词: 耐久度、已绑定、击杀人数、无法破坏

========================================
【材料保护逻辑】
========================================

【Paper/Feather】
- protectPaper = true时:
  - 只保留"已绑定"行
  - 其他所有行强制不隐藏

【Stick】
- 完全不受隐藏规则影响
- 所有行强制不隐藏

========================================
【原版属性移除逻辑】
========================================

【纹饰】
- 关键词: "已有升级"、"Upgrade"
- 隐藏时移除3行

【工具属性】
- 关键词: "在主手时"、"When in main hand"
- 隐藏时移除3行

【护甲属性】
- 关键词: "戴在头上时"、"穿在身上时"、"穿在腿上时"、"穿在脚上时"
- 额外: "盔甲韧性"、"击退抗性"
- 隐藏时移除2行

========================================
【构建输出逻辑】
========================================

【精简模式】（默认）
- 隐藏指定行
- 底部显示提示: "[按 {key} 查看 X 条隐藏信息]"

【展开模式】（按住自定义按键）
- 显示分隔线
- 连续输出所有隐藏行（不插入分组空行）

【空行处理】
- 去除开头的空行
- 合并连续空行（最多保留1个）

========================================
【代码优化点】
========================================

1. 附魔硬匹配: 304个附魔全部写入库中，不使用模糊匹配
2. 附魔描述硬匹配: 约170个描述关键词写入库中
3. 区域优先级: 附魔区最先识别，防止其他区域误判附魔描述
4. 附魔区域终止: 遇到其他区域开头立即停止附魔扫描
5. 老版本附魔: 标记后不再扫描描述，防止误判后续行
6. 工具文本精确匹配: 8个固定文本写入库中
7. 分隔线精确匹配: 12种格式写入库中
8. 变量模板: 装备类型+前缀组合识别
9. 自定义按键: 纯配置项控制，不注册KeyBinding，避免原版按键设置污染

========================================
【已知问题与注意事项】
========================================

1. 附魔描述扫描可能过度延伸（已修复: 增加终止条件）
2. 工具文本可能被误判（已修复: 精确匹配）
3. 套装信息可能被误判为技能（已修复: 保护关键词）
4. 空白行归属问题（已修复: D方案+相邻扩展）
5. 老版本附魔无描述（已处理: 不扫描描述）
6. 自定义按键不显示在原版按键设置中（设计如此，通过ModMenu配置）
